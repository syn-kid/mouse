# 项目记忆库

用于解决新对话"失忆"问题。用户明确说"保留/喜欢/记住"时，追加到本文件。

## 稳定事实
- 项目仓库：本地开发，尚未关联远程仓库
- 运行环境：Python 3.x + FastAPI + Uvicorn
- 服务启动：双击 `start.bat`，Uvicorn 监听 `0.0.0.0:8000`
- 数据规模：17 款鼠标垫（speed/balanced/control/rough）+ 12 款游戏 Yaw 校准
- 前端：单文件原生 HTML/CSS/JS，无框架依赖

## 偏好与红线

### 视觉
- 喜欢白底玻璃质感（acrylic）、舞台光高光、iOS 原生极简风格
- 喜欢物理驱动的动画（匀速旋转、正弦呼吸、余弦衰减）
- 喜欢留白营造"舞台感"，每屏一个视觉焦点
- 喜欢克制配色：墨蓝、薄荷绿、灰阶
- 拒绝廉价渐变、默认白框、太过平淡的设计

### 交互
- 动画须有物理基础，不做无意义的炫技动效
- 字体传递情感（Pinyon Script = 温柔，Manrope = 专注）

### 技术
- 前端保持零框架依赖，不引入 React/Vue 等
- 后端 FastAPI 保持轻量，算法参数谨慎调整
- 5 档灵敏度分档（high/mid_high/mid/mid_low/low）以 Valorant eDPI 为锚点
