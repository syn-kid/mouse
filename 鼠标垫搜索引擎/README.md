# DPI2Pad — 鼠标垫量化推荐引擎

基于鼠标 DPI + 游戏内灵敏度 + 游戏 Yaw 值，通过摩擦力学算法匹配最适合的鼠标垫。

## 快速开始

### 1. 初始化（仅首次）
双击 `setup.bat`，自动创建虚拟环境并安装依赖。

### 2. 启动服务
双击 `start.bat`，浏览器访问 **http://127.0.0.1:8000**

### 3. 使用
1. 选择游戏
2. 输入鼠标 DPI
3. 输入游戏内灵敏度
4. 点击「搜索匹配」或使用预设快速填充

## 算法逻辑

```
cm/360 = 360 / (DPI x Sens x Yaw) x 2.54
```

5 档灵敏度分档（以无畏契约 eDPI 为锚点）：

| 档位 | cm/360 | 推荐垫面 |
|------|--------|----------|
| 高敏 | < 29.0 | 涩垫 |
| 中高敏 | 29.0–35.3 | 控制垫 |
| 中敏 | 35.3–40.8 | 中性垫 |
| 中低敏 | 40.8–54.4 | 中性垫 |
| 低敏 | > 54.4 | 滑垫 |

涩垫为独立档位，不与控制垫混类。每类垫面有独立摩擦评分权重，并附带动态推力微调。

## 技术栈

- 后端: Python + FastAPI + Uvicorn
- 前端: 原生 HTML/CSS/JS（零框架依赖）
- 数据: 17 款主流鼠标垫，含静摩擦/动摩擦/制动实测数据
- 游戏: 12 款游戏 Yaw 值校准
